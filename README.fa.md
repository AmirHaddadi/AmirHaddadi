## 👋 درباره من

**توسعه‌دهنده فول استک وب و مهندس DevOps** با تمرکز بر ساخت سامانه‌های اختصاصی، امن و قابل نگهداری.

از معماری و توسعه بک‌اند تا اتصال فرانت‌اند، استقرار، نگهداری و بهینه‌سازی را پوشش می‌دهم. هدف، **مهندسی تمیز و راهکاری است که بعد از تحویل هم قابل اتکا و توسعه باشد.**

## 🧩 چه محصولاتی می‌سازم؟

| توسعه محصول | زیرساخت و DevOps | امنیت و پایداری |
|---|---|---|
| سامانه‌های اختصاصی تحت وب | استقرار روی Linux / VPS | JWT / Session / RBAC |
| SaaS و سامانه‌های چندمستأجره | CI/CD و فرآیند انتشار | امنیت API و Rate Limiting |
| CRM، داشبورد و ابزارهای سازمانی | Docker و Nginx | Backup / Rollback |
| فروشگاه و سامانه‌های داخلی | مانیتورینگ و نگهداری | بهینه‌سازی و مقیاس‌پذیری |
| REST API و قابلیت‌های Real-time | مدیریت سرور و Cloud | معماری ماژولار |


## 🛠️ استک اصلی

**بک‌اند:** Node.js · Express · NestJS · JavaScript · TypeScript · REST API · WebSocket  
**فرانت‌اند:** HTML · CSS · JavaScript · رابط‌های واکنش‌گرا  
**دیتابیس:** MongoDB  
**DevOps:** Linux · Docker · Nginx · GitHub Actions · Cloudflare · VPS  
**مهندسی:** معماری ماژولار · RBAC · JWT · Session Auth · امنیت API · بهینه‌سازی عملکرد
